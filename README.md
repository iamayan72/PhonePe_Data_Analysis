PhonePe Payment Insights Dashboard

#Project Overview

This project is an "interactive PhonePe Payment Insights Dashboard" created using "Microsoft Excel and Power BI".
The purpose of this project was to analyze payment transactions, understand user behaviour, compare transaction activity, and identify important business insights from the data.
I worked on the data from "cleaning and preparation to visualization and dashboard creation".

#Project Objectives

* Analyze total users and transactions.
* Track overall transaction value.
* Monitor payment success rate.
* Understand monthly transaction trends.
* Analyze users by age segments.
* Compare weekday and weekend usage.
* Identify top users by transaction value.
* Analyze transaction value by service.
* Compare different payment statuses.
* Present the results through an interactive Power BI dashboard.

#Dataset

The project contains user and transaction-related information such as:
* User ID
* User Name
* Age
* Join Date
* Transaction ID
* Transaction Date
* Transaction Amount
* Service
* Service Type
* Payment Status
* Transaction/Payment Reason
The data was first prepared in **Excel** and then imported into **Power BI** for analysis and visualization.

#Data Cleaning & Preparation

I used "Excel" to prepare the dataset before building the dashboard.

#Cleaning steps performed:

* Checked for missing values.
* Checked and removed duplicate records where required.
* Verified User IDs and Transaction IDs.
* Corrected date formats.
* Checked transaction amount values.
* Standardized payment status values.
* Checked service and service-type categories.
* Verified the overall data before importing it into Power BI.
* Created the required date structure for time-based analysis.
The main focus was to make the dataset **clean, consistent, and ready for reporting**.

#Power BI Dashboard

After preparing the data in Excel, I created an interactive dashboard in **Power BI**.

#Main KPI Cards

The dashboard displays:

* 👥 Total Users: 108K
* 🔄 Total Transactions: 300K
* 💰 Total Value: ₹3.47Bn
* ✅ Success Rate: 96.00%
These KPIs provide a quick overview of the overall payment performance.

#Dashboard Visuals

#Transaction Over Time

A line-based trend visual showing transaction activity and transaction value across different months.
This helps identify periods with higher and lower transaction activity.

#Age Segment Distribution

Users are divided into different age groups:

* Young Adults - (18 - 25)
* Adults - (26 - 40)
* Middle Age - (41 - 60)
The visual helps understand which age segment has the largest user base.

#Service Transaction Value

A bar chart comparing transaction value across different services, including:
* Loans
* Insurance
* Money Transfer
* Recharge & Bills

#Top 5 Users

Shows the "top 5 users based on transaction value", helping identify high-value users.

#Weekday vs Weekend Usage

A donut chart comparing transaction activity between:
* Weekdays
* Weekends

#Payment Status

Payment status can be filtered using the dashboard slicer to analyze different transaction outcomes.

#Interactive Features

The dashboard includes interactive filters for:
* "Month"
* "Payment Status"
Users can select different months or payment statuses and the dashboard visuals update accordingly.

# Key Business Insights

* Middle-age users form the largest user segment.
* Payment success rate is 96%, showing strong transaction performance.
* Weekday transaction activity is higher than weekend activity.
* May and July show high transaction activity.
* Loans contribute the highest transaction value among the major services.
